# Average Sensor Readings

## Project Purpose
This project is a simple Python script designed to calculate and display the total count, minimum, maximum, and average of a specific set of sensor readings.

## The Readings
The program processes the following dataset: `[22, 24, 26, 28, 30]`

## How to Run
1. Ensure Python is installed, or open the code in an online environment like Google Colab.
2. Run the `main.py` script.
3. The expected results are: count = 5, minimum = 22, maximum = 30, average = 26.0# aict-cloud-assignment-2
